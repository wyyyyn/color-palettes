# 设计实验室 · color-palettes

> 一个能玩起来的设计系统。八个菜单各选一项，整套界面当场长出来。挑到满意的，一键带进你自己的项目。

打开一个网页，像调音台一样推动八个维度，配色、字体、排版、调性、氛围、图标、花纹、元件实时合成在同一个示例站点上。看顺眼了就复制走，连字体和图标都一起打包，离线可用。

```
配色 40 × 字体 24 × 排版 6 × 调性 6 × 氛围 6 × 图标 13 × 花纹 17 × 元件 8
```

这是几十万种可组合的视觉方案，全部即看即得。

---

## 立即体验

**本地**：克隆仓库，浏览器直接打开 `preview.html`。零安装、零构建、零依赖。

**在线**：仓库 Settings → Pages 指向 `main` 根目录后，访问

```
https://wyyyyn.github.io/color-palettes/
```

打开就能玩，不需要账号，不上传任何东西。

---

## 五分钟上手

1. **挑一套起点**。每个菜单点一项，示例站点立刻变成那套样子，所见即所得。
2. **没灵感就洗牌**。按 `空格` 随机来一套组合，反复按，直到某一屏让你眼前一亮。
3. **锁住喜欢的维度**。配色满意但想换字体？点配色那一轴的锁，再洗牌时它不动，只换其他维度。
4. **分享与对比**。当前组合会写进网址，复制链接发给同事即可还原；存两个快照可以 A·B 并排比较。
5. **带走它**。右上「复制 / 导出」给你三样东西：CSS 变量、字体引入链接、一份 JSON 配置。粘进项目就生效。

全程支持中文 / English 切换，键盘也能操作。

## 八个菜单分别在调什么

| 菜单 | 一句话 | 例子 |
|------|--------|------|
| **配色** | 整页的颜色性格 | 旧书店温润、东方美学、暗黑炽烈、海岸亚麻 |
| **字体** | 标题与正文的气质 | 编辑感、杂志、瑞士、文学、终端、古典 |
| **排版** | 字号、留白与节奏 | 宽松编辑、紧凑高密度、海报巨字、仪表盘 |
| **调性** | 形状语言 | 方角描边、圆角胶囊、细线极简、粗边硬投影 |
| **氛围** | 空气感与质地 | 纸纹、画廊留白、终端扫描线、夜色晕影 |
| **图标** | 同一组图标的画风 | 线条、粗体、双色、填充等 13 种风格 |
| **花纹** | 背景底纹与装饰 | 网点、青海波、水磨石、孟菲斯、蓝图等 |
| **元件** | 按钮 / 卡片 / 标签长相 | 取材成熟开源组件系统的 8 套配方 |

配色全库以低饱和为基调，刻意避开高饱和紫，整体偏耐看的高级感。

## 带进你自己的项目

挑好的组合不只是截图好看，它能落地成代码。

1. 在预览页点「复制 / 导出」，拿到 bundle。
2. 把 CSS 变量贴进项目主样式（纯 CSS、Tailwind v4、shadcn/ui、Next.js、Vite 都有现成写法）。
3. 引入用到的字体，跑起来对比一下，确认对比度达标。

字体、图标、花纹全部内置在 `assets/`，无需联网、无需 CDN，整目录拷过去就能用，适合内网或离线环境。完整的分步落地流程，以及「把某个现成网站的气质收敛到最接近的一套组合」的反向玩法，都写在 [`SKILL.md`](./SKILL.md)。

## 它适合谁

- 想快速给项目定一套视觉基调，又不想从零调色的人
- 设计与开发之间需要一个能边玩边对齐的中间地带
- 喜欢可控、语义化、能复用的设计 token，而非一次性硬编码
